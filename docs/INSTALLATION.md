# 🛠️ EcoGuard Setup & Installation Guide

## Prerequisites
- **Node.js**: v18.0.0+
- **Docker & Docker Compose**: (Optional for containerized setup)
- **Python**: v3.9+ (For Edge AI simulator)

## Local Development Setup

### 1. Clone Repository
```bash
git clone https://github.com/dharan15777/EcoGuard-AI-system.git
cd EcoGuard-AI-system
```

### 2. Backend Setup
```bash
npm install
npm run start
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### 4. Run Sensor Simulator
```bash
node scripts/simulator.js
```
