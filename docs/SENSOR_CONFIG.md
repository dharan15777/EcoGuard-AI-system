# 📡 Sensor Configuration Guide

EcoGuard supports four sensor families:
1. **FLOOD_WATER_LEVEL**: Ultrasonic stage sensors + hydrostatic pressure transducers.
2. **WILDFIRE_THERMAL**: Flir Thermal IR arrays + CO2 gas sensors.
3. **AIR_QUALITY_AQI**: Laser PM2.5/PM10 particle counters.
4. **LANDSLIDE_SOIL_MOISTURE**: Multi-depth TDR soil probes + MEMS accelerometers.
