# 📘 EcoGuard Command Center User Guide

Welcome to the EcoGuard AI Operations Manual.

### Key Workflows:
- **Monitoring Active Hazards**: Open the Live GIS Dashboard to inspect thermal and hydro sensor nodes in real-time.
- **Acknowledging Alerts**: Click on red high-priority alert cards to view sensor telemetry history and confirm reception.
- **Sensor Management**: Add new LoRaWAN micro-nodes by entering GPS coordinates and selecting appropriate TensorFlow Lite models.
